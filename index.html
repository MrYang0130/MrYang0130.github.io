文档合规审核 Agent Agent 开发
2024.07 – 至今
项目背景

企业合同、制度等文件分散在业务系统中，合规审查依赖人工逐条比对内部合规制度，存在效率低、 口径不一致、结论难追溯的问题；业务方上传文件后，需要自动完成审核并通知结果。

项目目标

构建可审计、可解释、可降级的文档合规审核 Agent，覆盖 PDF / Word / Excel / PPT 及扫描件。 从企业合规文档生成可版本化的规则清单，审核结论可追溯到文件原文与合规条款原文。 后台异步完成审核，通过签名 Webhook 回调业务系统；高风险或模型不可用时转人工，避免错误放行。

个人职责
  • 负责整体方案与 0→1 落地：URL + MCP 取件、确定性规则 + RAG + LLM 混合审核、签名 Webhook 回调。
  • 设计 7 阶段审核流水线（取件 / 提取 / 规则 / RAG+LLM / 聚合 / 回调），实现阶段级幂等、Outbox + 定时补偿，worker 可水平扩展。
  • 建设合规知识库与规则生产链路：分块 → 向量化 → 混合检索 → LLM 抽取检查项 → 来源校验 → 人工激活 → 版本化。
  • 设计证据校验与安全边界：引文与原文 block 匹配、页码由 block 推导、未验证高风险转人工；提示注入检测、SSRF 白名单、zip bomb 防护。
  • 建立评测与可观测：检索 recall、finding precision / recall、阶段耗时、token / 成本；85 项测试覆盖规则、流水线、幂等与回调。
